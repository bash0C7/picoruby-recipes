# PicoRuby デモ v2 - 使用ガイド

## 概要

ATOM MatrixとPicoRubyを使った、MIDIとIMUの統合インタラクティブデモです。
加速度センサーでシンセサイザーをリアルタイム制御しながら、フィンガードラム演奏でLEDを動的に光らせます。

## 実装機能

### 1. 押しスイッチによる消灯/点灯
- **押しスイッチ** (GPIO 39): ボタンを押すたびに点灯⇔消灯切り替え

### 2. 加速度センサーでMIDI CCコントロール
- **MPU6886 (加速度センサー)**: パイプを傾けてシンセサイザーをコントロール
  - **X軸**: レゾナンス (MIDI CC#71)
  - **Y軸**: カットオフフィルター (MIDI CC#74)
  - **Z軸**: リバーブ (MIDI CC#91)
  
  各軸の傾きを0-127の範囲に変換してMIDI CC送信

### 3. キーボード操作によるフィンガードラム + LED可視化
- PC側でキーボード入力 → MIDI Note生成 → ATOM Matrix → MIDI Unit
- **LED可視化**: 
  - ノート番号36-84を60個のLED位置にマッピング
  - セミトーン（12音階）で色が変化（赤→オレンジ→黄→緑→シアン→青→紫→マゼンタ→赤）
  - オクターブで位置をシフト
  - ベロシティで明るさ制御
  - 周辺LEDにフェード効果
  - 自然な減衰表現

## ハードウェア構成

```
ATOM Matrix
├── LED Strip (GPIO 22): 60個のWS2812 LEDs
├── Button (GPIO 39): 押しスイッチ (内蔵)
├── MPU6886 (GPIO 25/21): 加速度センサー (I2C, 内蔵)
├── PC UART (USB): キーボード入力受信
└── MIDI Unit (GPIO 26/32): 音源モジュール (UART1, Grove)
```

## セットアップ

### ATOM Matrix側

1. **ファイル配置**
   ```bash
   cp demo_full.rb src_components/R2P2-ESP32/storage/home/
   ```

2. **ビルド＆フラッシュ**
   ```bash
   rake build
   rake flash
   ```

### PC側

1. **依存関係インストール**
   ```bash
   cd src_components/pc
   bundle install
   ```

2. **実行**
   ```bash
   ruby drum_pc.rb
   ```

## 使い方

### 基本操作

1. **電源ON**: ATOM Matrixに電源を入れる
2. **デモ起動**: `demo_full.rb`が自動実行される
3. **初期キャリブレーション**: 水平に置いて5秒待つ（IMU基準値設定）

### 消灯/点灯

**押しスイッチ**:
- ATOM Matrix中央のボタンを押すたびに切り替え

### IMUコントロール（MIDI CC送信）

パイプを傾けると、シンセサイザーのパラメータがリアルタイム変化：

**X軸（左右）**: レゾナンス
- 左に傾ける: レゾナンス減少（マイルドな音）
- 右に傾ける: レゾナンス増加（キンキンした音）

**Y軸（前後）**: カットオフフィルター
- 前に傾ける: カットオフ減少（こもった音）
- 後に傾ける: カットオフ増加（明るい音）

**Z軸（上下）**: リバーブ
- 下に傾ける: リバーブ減少（ドライ）
- 上に傾ける: リバーブ増加（空間的）

### フィンガードラム + LED可視化

**キーマップ:**
```
【下段】
z: キック (Bass Drum)
x: スネア (Snare)
c: クローズハイハット
v: オープンハイハット
b: クラッシュシンバル
n: ライドシンバル
m: ハンドクラップ

【上段】
a-h: 各種タム

【数字】
1: カウベル
2: タンバリン
3: チャイナシンバル
4: スプラッシュシンバル

q: 終了
```

**LED可視化の仕組み:**
- 各ノートが60個のLEDの特定位置に対応
- セミトーン（音階）で色が決まる
  - C: 赤
  - C#: 赤オレンジ
  - D: オレンジ
  - D#: 黄オレンジ
  - E: 黄
  - F: 黄緑
  - F#: 緑
  - G: シアン緑
  - G#: シアン
  - A: 青シアン
  - A#: 青
  - B: 紫
- ベロシティ（打鍵の強さ）で明るさ変化
- Note Off後も自然にフェードアウト
- 周辺LEDに光が広がる効果

**演奏Tips:**
- 強く打鍵すると明るく光る
- 同時押しで複数位置が光る
- リズムパターンで光の流れを作れる
- IMUを動かしながら演奏すると音色変化と光の変化が同期

## 実装の技術詳細

### LED可視化のマッピング

ノート番号36-84（C2-C6）を60個のLEDに配置：

```
位置 = (セミトーン × 5) + オクターブ
セミトーン = (ノート番号 - 36) % 12
オクターブ = (ノート番号 - 36) / 12
```

例:
- C2 (36): 位置0
- C#2 (37): 位置5
- D2 (38): 位置10
- C3 (48): 位置1
- C4 (60): 位置2

### MIDI CCの範囲マッピング

加速度センサーの値（-2G 〜 +2G）を0-127に変換：

```ruby
# -200 〜 +200（整数化）を 0〜127 にマッピング
cc_value = ((diff + 200) * 127 / 400).to_i
```

### フェード効果

Note Off後も即座に消灯せず、フレームごとに97%に減衰：

```ruby
brightness = brightness * 0.97
```

約70フレーム（1.4秒）で自然に消える

## トラブルシューティング

### MIDIが聞こえない

- MIDI Unitの接続確認（Grove: GPIO 26/32）
- ボーレート31250bps確認
- Program Change送信確認（初期化時）

### LEDが光らない

- PC接続確認（USB Type-C）
- drum_pc.rb実行確認
- ボタンで点灯/消灯状態確認

### IMU制御が効かない

- 水平位置で5秒待ってキャリブレーション
- 大きくゆっくり傾ける
- MIDI Unit側がCC対応か確認

## パフォーマンスのコツ

1. **音色変化**: IMUをゆっくり大きく動かす
2. **リズム演奏**: キーボードで安定したビートを刻む
3. **複合パフォーマンス**: 
   - 左手でIMU操作（音色制御）
   - 右手でキーボード演奏（リズム＋光）
4. **光の演出**: 
   - 高音域（数字キー付近）→右側LED
   - 低音域（z付近）→左側LED
   - 同時押しで複数箇所点灯
